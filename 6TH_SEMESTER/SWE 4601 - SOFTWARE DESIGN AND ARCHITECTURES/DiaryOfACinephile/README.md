## Installation

Instructions to prepare the project locally.

1. Install dependencies in the root

```
npm install
```

2. Add Firebase config credentials in the `firebaseConfig.js` file.

## Running

```
npx expo start

(with an emulator or the expo go app or the web - works best with the mobile view)
```
